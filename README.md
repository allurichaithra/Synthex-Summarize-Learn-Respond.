Synthex- Fully Functional Chrome extension that instantly summarizes web pages, emails, and study notes, while generating AI-powered flashcards to boost productivity and learn
Insert your api key in service_worker.js
Install:
Go to chrome://extensions -> Enable Developer Mode -> Load unpacked -> select the folder Synthex_v5
Notes:
- The service_worker.js currently includes an embedded API key for local testing at the same path per your request.
- Flashcards generation enforces JSON output and retries; fallback parsing ensures you always get cards.
